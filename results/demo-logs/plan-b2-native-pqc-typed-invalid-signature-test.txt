Plan B2.2 Native PQC Typed Transaction Invalid Signature Test

Purpose:
Verify that a native typed PQC transaction using TransactionType.PQC / 0x05 is rejected by Besu when its ML-DSA-65 signature is invalid.

Method:
eth_sendRawTransaction

Raw transaction format:
0x05 || RLP([
  chainId,
  accountNonce,
  gasPrice,
  gasLimit,
  to,
  value,
  payload,
  pqAlgorithm,
  pqPublicKey,
  pqSignature
])

Observed local result:
Native transaction type: 0x05
Algorithm: ML-DSA-65
Local valid after tamper: false
PQC sender: 0x2079556b05074f99b47f335d7f2ac7996fc13b6b
pqNonce: 1
accountNonce: 0
pqPublicKeyBytes: 1952
pqSignatureBytes: 3309
txDigest: 0x23ad4af61a534fb11f6da3b653040159fccfe82c80ac913ccbbf1d7a0acb5d6f

Observed Besu RPC result:
HTTP status: 200
JSON-RPC error code: -32002
JSON-RPC error message: Invalid signature

Conclusion:
Besu rejects an invalid native PQC typed transaction through eth_sendRawTransaction.
This confirms that TransactionType.PQC / 0x05 is decoded and that native transaction validation rejects an invalid ML-DSA-65 signature.
