Relayer Gateway Nonce Replay Test

Purpose:
Verify that the PQC Gateway rejects reused pqNonce for the same PQC sender.

Test sequence:
1. Send valid raw PQC transaction with fixed demo keypair and pqNonce = 1.
2. Send another raw PQC transaction with the same fixed demo keypair and pqNonce = 1.
3. Send another raw PQC transaction with the same fixed demo keypair and pqNonce = 2.

Expected behavior:
- First transaction should be accepted.
- Second transaction should be rejected because pqNonce = 1 was already used.
- Third transaction should be accepted because pqNonce = 2 is the next expected nonce.

Observed behavior:
[OK] First transaction with pqNonce = 1 was accepted.
[OK] Second transaction with pqNonce = 1 was rejected by nonce-check.
[OK] Third transaction with pqNonce = 2 was accepted.

Conclusion:
The PQC Gateway provides replay protection using pqNonce per PQC sender.
